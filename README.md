 # Country Explorer 🌍

Country Explorer is a simple web application that allows users to search for countries and view basic information.

## Features
  Country search
  Flag display
  Capital, region, population
  Currency and languages
  Country suggestions while typing

## Technologies Used
  HTML
  CSS
  JavaScript
  REST Countries API
